# How Much AI Is in This Track? (companion page)

Static page for the ISMIR 2026 paper. No build step: GitHub Pages serves `index.html` as is.

## Deploy
1. Push this folder to a repo (or to `/docs` in an existing one).
2. Settings > Pages > Deploy from a branch > pick the branch and folder.

## Links
- Live page: https://fergarciadlc.github.io/ismir26-how-much-ai/
- MSc thesis: https://zenodo.org/records/23186445

## Assets
- `assets/figs/`: figures cropped from the thesis PDF (same data as the paper).
- `assets/slides.pdf`: the 3-minute presentation slides.
- `assets/diagrams/architecture.svg`: standalone copy of the architecture diagram (the page uses an inline copy so it follows dark mode).
- `assets/logos/`, `assets/img/`: logos, the title illustration and the social preview card.
